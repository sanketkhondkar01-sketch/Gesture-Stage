# 🖐️ Gesture Stage

**Gesture Stage** is a fun, browser-based hand-gesture animation project. It uses your webcam to detect simple hand gestures and triggers colorful visual effects in real time.

Show your hand to the camera, make a gesture, and watch the animation respond instantly!

## ✨ Features

- 📷 Uses the webcam for real-time hand-gesture detection
- 🎨 **Open palm** → Color burst animation
- 👊 **Fist** → Shockwave rings
- ✌️ **Peace sign** → Confetti shower
- 👍 **Thumbs up** → Floating hearts
- ☝️ **Point** → Glowing trail
- 🤏 **Pinch** → Energy orb effect
- 🌐 Runs directly in the browser—no installation required

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone [https://github.com/your-username/gesture-stage.git](https://github.com/your-username/gesture-stage.git)
cd gesture-stage
```

### 2. Open the project

Open `gesture-stage.html` in any modern web browser.

You can also run it using a local server:

```bash
# Python 3
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000/gesture-stage.html
```

### 3. Allow camera access

Click **Start camera** and allow browser permission to access your webcam.

> ⚠️ Camera access requires a secure context. Use `https://` or `http://localhost`.
